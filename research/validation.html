Scope and failure accounting

Each table keeps its own sample and reference contract. There is no pooled score across author quadrilaterals, Duke occupancy masks and the provisional ROI. All selected cases remain denominators; a failed run retains every reference as a false negative, and reported false positives cover completed outputs only.

PV-Hawk uses native 640 px tiles and fixed RGB settings, with no centered tile-edge recovery. The original confidence is 0.9; only the separate ablation changes it to 0.25. CVUT and Stage1 use the existing pipeline sampling. This is an operational pipeline comparison, not a controlled architecture ranking. Each tested configuration was sealed before its own measurements.

No perfection, commercial reliability, general thermal reliability or validation on the user's Matrice 4T surveys is claimed. Capture-specific independent labels are still needed.
